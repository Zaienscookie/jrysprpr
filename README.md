# jrysprpr - 今日运势

群里发 **`今日运势`**（或 `运势` / `jrys`），查看今天的运势。

## 命令
| 命令 | 说明 |
|------|------|
| `今日运势` / `运势` / `jrys` | 查看今日运势 |

## 特性
- **按群友区分**：运势按 群ID+QQ号+日期 确定性生成，同人同天固定，不同人结果不同
- **跨天刷新**：第二天自动生成新运势
- **数据持久化**：结果存 `data.json`，重启不丢；当天重复查看返回同一份
- **多样性**：大吉~大凶 8 档、4 维度、幸运色/数字/物、宜忌、点评，文案池丰富

## 数据
- `data.json`：自动生成，格式 `群ID -> 用户ID -> 当日运势`
- 清空数据：删掉 data.json 即可
