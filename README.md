# jrysprpr - 今日运势

群里发 **`今日运势`**（或 `运势` / `jrys`），查看今天的运势。

## 命令
| 命令 | 说明 |
|------|------|
| `今日运势` / `运势` / `jrys` | 查看今日运势 |
| `重抽运势` / `jrysreroll` | 重抽一次今日运势（每天限 1 次） |
| `运势统计` / `jrysstat` | 近 30 天个人运势统计（最佳/最差/平均/等级分布） |
| `运势排行` / `jrysrank` / `今日榜` | 本群今日运势榜 TOP3 |
| `运势帮助` / `jryshelp` | 命令说明 |

## 特性
- **多群同步**：运势按 用户ID+日期 确定性生成，同一人在所有群查到的是同一份
- **凌晨刷新**：每天凌晨 0 点自动刷新新运势（自然日）
- **数据持久化**：结果存 `data.json`，重启不丢；当前运势期重复查看返回同一份
- **多样性**：大吉~大凶 8 档、4 维度进度条、幸运色/数字/物/方位/时刻/关键词、宜忌、点评、格言，文案池丰富
- **重抽**：每天可重抽 1 次，结果用不同随机盐生成
- **统计/排行**：历史保留 30 天做个人统计；按最近活跃群做当日 TOP3

## 数据
- `data.json`：自动生成，格式 `用户ID -> {日期 -> 当日运势}`，只保留最近 30 天
- 清空数据：删掉 data.json 即可
